# Resume ATS Analyzer using RAG

A Resume ATS Analyzer built using **Retrieval-Augmented Generation (RAG)** that analyzes a resume PDF against a given job description and provides an estimated ATS compatibility score.

## 🚀 Project Overview

This project allows users to upload their resume in PDF format and provide a job description. The system extracts the resume content, converts it into vector embeddings, stores the embeddings in a FAISS vector database, retrieves relevant resume information, and uses a Groq-powered LLM to generate an ATS analysis.

## 🔄 Workflow

**Resume PDF → Text Extraction → Text Chunking → Vector Embeddings → FAISS Vector Database → Relevant Information Retrieval → Groq LLM → ATS Score & Analysis**

## 🛠️ Technologies Used

* Python
* Google Colab
* PyPDF
* Sentence Transformers
* FAISS
* Groq API
* Llama 3.3 70B
* RAG (Retrieval-Augmented Generation)
* Vector Embeddings

## ✨ Features

* Upload a resume PDF
* Extract text from the resume
* Generate vector embeddings
* Store resume data in a FAISS vector database
* Compare resume content with a job description
* Generate an estimated ATS compatibility score
* Identify matching skills and keywords
* Identify missing or weak keywords
* Analyze education, projects, and experience
* Provide suggestions for improving the resume
* Ask follow-up questions about the resume

## 📊 Sample Output

The chatbot provides:

* **ATS Score:** XX/100
* **Matching Skills**
* **Missing or Weak Keywords**
* **Education Match**
* **Project/Experience Match**
* **Keyword Match**
* **Resume Strengths**
* **Improvement Suggestions**
* **Final Recommendations**

## 🎯 Purpose

The goal of this project is to demonstrate how **RAG, vector databases, embeddings, and Large Language Models** can be combined to build an AI-powered resume analysis application.

> Note: The ATS score generated by this project is an estimated compatibility score and does not represent the score of any specific company's ATS system.
